Viewer Capabilities

Fontager Viewer is packed with features to inspect and install your fonts effortlessly.

Instant Preview

Lightning-fast previews of .ttf, .otf, .ttc, and .woff2 files without requiring system installation.

Waterfall View

Preview typography at multiple sizes simultaneously to check readability across different scales.

Glyph Grid

Browse every character with Unicode code points, smart block filters, and search capabilities.

Deep Metadata

Examine family properties, designer details, licenses, versioning, OS/2, and head tables directly.

Drag & Drop

Simply drop font files onto the application to instantly load, inspect and manage them.

System Integration

Set as default font handler, install for current user or all users seamlessly with proper UAC.

Native UI

Modern WinUI 3 Design

Built exclusively for Windows 10 & 11, Fontager leverages the latest Windows App SDK. Enjoy smooth Mica and Acrylic backdrops, fluid animations, and a design language that feels native to your operating system while performing incredibly fast.

Coverage

Complete Glyph Coverage

Don't be limited by basic Latin previews. Fontager accurately reads cmap tables (formats 0, 4, 6, 12) to show exactly what a font contains, complete with category and block filters. Ideal for finding hidden symbols and inspecting multi-language fonts.

Inspection

Extensive Metadata Inspector

Dive deep into font internals with our custom binary FontParser. Check typographic family names, licensing details, Panose classifications, and supported Unicode ranges all without relying on external libraries.

Compact UI

Compact Interface

Perfect for quick lookups and limited screen real estate. Fontager collapses into a compact window, providing instant access to font previews and essential metadata without cluttering your workspace.
